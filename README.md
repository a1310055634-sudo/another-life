# 另一种人生

现代都市题材单机网页版人生模拟器。从 18 岁开始，每年经历一次抉择，通过教育、职业、金钱、关系与健康的选择走向 16 种结局之一。一局约 15～25 分钟，全程离线运行，无需账号、不联网。

- 技术栈：React 18 + TypeScript + Vite + Vitest
- 内容规模（V7）：**349 个事件**（六类全覆盖 18-77 六桶；V5+V6+V7 三轮扩容自 290，V7 新增 59：心理/育儿/同事邻里/创业/遗嘱/年关/养老/性格/时代纵深 IV/新线联动/老线补密）、**16 种结局**（各配 2~3 变体后记，按人生形态定向分派）、**66 个成就**（稀有度四级，含 V7 机制成就七枚：白手起家/求助的勇气/良师父母/远亲不如近邻/十年归途/家风相传/安其所）、**11 个岗位 × 4 职级**逐级头衔、900+ 个选项（每事件 2~4 个，无单选事件）、**6 个存储键**
- V2 新增玩法：公式化收入曲线与通胀、房贷真实余额（提前还款）、生活方式长因果（吸烟/久坐/锻炼→健康风险→分级体检与慢性病）、关系年度衰减与维护、子女生命阶段里程碑、年度快照驱动的**资产曲线 / 属性雷达 / 人生报告**（结局页报告式版面：评级印章、关键数据五格、关键抉择金句）、跨年转场与结算动效、氛围音效（默认静音）、移动端触控适配
- V3 新增玩法：**父母去世线**（病危→陪伴→葬礼→忌日，送别与哀伤期）、**慢性病长期管理**（复查/并发症/带病延年）、**婚恋五入口**（相亲/旧识/同事/兴趣班/交友软件）与后记人生形态定向分派、**往生录**（多周目博物馆：每段人生一块碑+跨周目成就收集）、**人生报告分享卡**（canvas 绘制 PNG 下载）、关系取名池（伴侣/孩子/孙辈具名）、晚年日常 8 事件（热力补密）、**全键盘可玩**（数字键选择/Enter 推进/C 折叠）、首局开场引导（三步可跳过）、音量三态（关/低/高）与 reduced-motion 联动、WCAG AA 对比度

## 离线版（双击即玩）

`npm run build` 产出的 `dist/index.html` 是**自包含单文件**（JS/CSS 已内联，无外部音频/图片资源），直接双击打开即可游玩，无需任何服务器。

- 也可以在地址栏打开 `file:///D:/vibe%20coding/another-life/dist/index.html`
- 之所以做内联处理：Chrome 对 `file://` 页面里的外部 `type="module"` 脚本强制 CORS 校验（`CorsDisabledScheme`），普通 Vite 构建双击打开会白屏；`npm run build` 已自动完成 `vite build` + 相对路径 + 内联（`scripts/inline-dist.mjs`）
- 离线版与开发版功能一致：创建角色、事件选择、跨年、自动存档、续玩、结局（人生报告）全部可用

## 存档说明

存档保存在浏览器 `localStorage`，共 **6 个独立键**，均与存档数据互不干扰：

| 键 | 内容 |
|---|---|
| `another-life:save` | 游戏存档（**存档版本恒为 v2**，旧档自动迁移：缺快照补空数组、从加载当年起继续积累）。单槽自动覆盖：创建角色、每次选择结算、每次进入下一年都会自动保存。到达结局后自动存档清除（结局是终点）。存档损坏、来自更高版本、字段非法时：一律拒绝读取并**保留原档**（可导出排查），不会白屏或覆盖。隐私模式或配额不足时游戏页出现保存失败横幅并提供导出按钮 |
| `another-life:legacy` | 往生录（多周目博物馆：每段走完的人生留一块碑，跨周目成就收集，50 条 FIFO，可清空） |
| `another-life:sound` | 氛围音效偏好（关/低/高三态），默认关闭，首页可开 |
| `another-life:ambient` | 人生阶段环境音偏好（三段合成底噪，默认关，音量跟随音效三态） |
| `another-life:tutorial` | 开场引导记忆（首局三步引导，完成或跳过即不再出现） |
| `another-life:bloodline` | 世代传承血脉（承继代数/家族姓氏/遗产/先辈信息）。**键值不进存档**——`GameState` 顶层无任何 bloodline 字段，存档 v2 结构零改动（单测锁定） |

- 首页「继续游戏」可从上次进度接着玩；「开始新人生」会就地确认后覆盖旧存档
- 首页与游戏页提供**导出/导入 JSON**：用于跨浏览器迁移、备份，或存储不可用时的救生通道
- V5 新增的房产 `home` / 保单 `insurance` / 基金 `fund` / 城市 `city` 四个字段均为**可选 + 带校验**，旧档缺字段即按"无房/无保单/无基金/老家"正常语义降级

## 设计约束（摘自 SPEC）

- 规则逻辑全部在 `engine/` 纯函数，事件文本与选项在 `data/events/`，React 组件只负责显示
- 随机数使用 mulberry32 可设 seed，`GameState.seed` 记录，同一 seed 可复现同一局
- **随机支流纪律**：非事件类随机（名声走红窗、传承血统派生、宠物定寿、年志氛围行等）一律走 seed 派生的独立散列或独立 rng 实例，**禁止消耗主 rng 流**——否则确定性基线（G5 18 局零位移）会整体位移
- 属性 0～100 用 clamp 收敛；金钱允许负债，经 `sanitizeMoney` 收敛，杜绝 NaN 传播
- 普通事件必须提供至少 2 个有效选项（唯一例外：低健康强制剧情 `hlt_body_intensive`，白名单受测试锁定）
- **存档版本恒为 v2 永不升版**：新字段一律可选 + validate + 旧档兼容测试（缺字段 = 正常语义）；跨代信息走独立键
- **无日历年字段**：`GameState` 不含年份，一切周期机制（牛熊/行业周期/世代）按玩家年龄锚定
- 事件内容红线：禁赌/禁毒/禁网贷题材、灰色风险线、同性伴侣线；事件不假设玩家有配偶/孩子/房产/积蓄/稳定工作等（须按 `tags`/`city` 等门控）
- 视觉样式全部走 CSS token（`index.css :root`），音效为 WebAudio 现场合成（无外部资源）
